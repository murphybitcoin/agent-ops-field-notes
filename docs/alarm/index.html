寝る前の準備（iPhone）
  1. 設定 → 画面表示と明るさ → 自動ロック →「なし」
  2. 低電力モードをオフにして、充電器につなぐ
  3. Bluetoothのイヤホンやスピーカーを外す（音がそちらに行くため）
  4. サイレントにしたまま「テスト」を押し、鳴っている間に音量ボタンで大きくする
  5. 「見張り開始」を押す。Safariはこのページを開いたままにする
  6. 「画面を暗くする」を押して寝る（画面は消えません）

鳴るのは、このページが画面に出ている間だけです。画面のロック、ほかのアプリへの切り替え、電池切れでは鳴りません。見張り中は、ほかのアプリの音楽が止まります。

記録

    価格はBinanceの公開データ（ログイン不要）から取っています。このページは取引や口座には触れません。鳴らないこともあるので、大事なポジションは取引所の注文（TP/SL）でも守ってください。
